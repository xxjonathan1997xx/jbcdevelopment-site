Support

Support for JBC apps and software.

Use this page for app support, Mac setup, download questions, privacy questions, or general contact with JBC Software Development LLC.

Contact support

Email jbcsdevs@gmail.com for support, app, download, setup, privacy, or software questions.

What to include

For the fastest review, include:

  • Your name and the app, software, or download you are asking about.
  • A short description of the issue or request.
  • The device, browser, or operating system if this is a technical issue.
  • Steps to reproduce a bug, if relevant.
  • Any screenshot or error message that helps explain the issue.

App support

For current or future JBC Software Development LLC apps, include the app name and the version number if available. App-specific support links may be added as each product is released.

NextRole support

NextRole is a job-search organizer for creating structured resumes, saving opportunities, tracking applications, and planning next steps. For help, email jbcsdevs@gmail.com and include NextRole in the subject line.

Support is available for:

  • Sign-in and magic-link delivery problems.
  • Resume editing, preview, printing, and PDF export.
  • Saved jobs, application tracking, search strategy, and account settings.
  • Account data export and permanent account deletion.

Do not send passwords, complete resumes, application notes, or other sensitive job-search information by email unless it is needed to resolve the request.

Wave Rush! support

Wave Rush! is an offline jet-ski racing game with five courses, a Championship mode, and a Single Race mode. For help, email jonathan@jbcdevelopment.dev and include Wave Rush in the subject line.

Support is available for:

  • Gameplay questions — controls, difficulty, medals, and scoring.
  • Bugs, crashes, or visual issues on a specific track or device.
  • Accessibility settings, including Reduce Motion.
  • Lost best scores after reinstalling or switching devices — scores are stored locally on the device only and do not transfer automatically.

There is no account or sign-in for Wave Rush!, so there is nothing to recover or reset beyond what is described above.

M5SteamBridge setup and troubleshooting

M5SteamBridge is a Steam setup helper for user-installed compatibility backends. It does not include Steam, games, Whisky, CrossOver, Wine bottles, proprietary runtimes, or any anti-cheat, DRM, ownership, platform, or account bypass.

  • Install your own compatibility backend, then run the first-run setup checks inside M5SteamBridge.
  • Use your own Steam installer, Steam account, and owned games.
  • Start with one owned lightweight game, run Check Game, then try the safe or performance profile before testing more titles.
  • If a game fails, capture diagnostics with preview enabled so private account data can be reviewed before sending anything.

For support, include your backend, game name, Steam App ID if known, health-check result, selected profile, and the visible error message. Compatibility is game-by-game.

Safety and privacy

Do not send passwords, payment details, private customer records, or other sensitive data by email unless a secure process has been approved first.

Response expectations

Support requests are reviewed manually. No automatic support tickets, proposals, billing, deployments, or external actions are created from this website.
