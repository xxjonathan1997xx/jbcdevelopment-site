## VOICEOVER
M5SteamBridge is a free local Mac app that helps you set up Windows Steam through your own compatibility backend.

You provide Steam, your account, your owned games, and a backend like Whisky or CrossOver.

M5SteamBridge checks the setup, helps install DXVK when needed, opens Steam, scans installed games, and suggests per-game launch profiles.

Start with one lightweight game you already own.

Run Check Game, try a safe or performance profile, and use diagnostics preview if something fails.

Some games will not work, especially when anti-cheat, DRM, launcher behavior, or platform restrictions block compatibility.

This app does not bypass those systems. It helps you test and troubleshoot game-by-game.
