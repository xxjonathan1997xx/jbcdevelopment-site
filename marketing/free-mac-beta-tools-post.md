## Short Post
I released two free local Mac tools from JBC Development:

PhotoMesh Studio helps turn object photos into a local photo-to-GLB workflow for game assets. With a user-configured Stable Fast 3D local setup, it can reconstruct a raw GLB, inspect asset health, optimize exports, create fixes, generate LODs, and build Unity, Godot, and Three.js packs.

M5SteamBridge helps Mac users set up Windows Steam through their own compatibility backend like Whisky or CrossOver. It checks first-run setup, opens Steam, scans installed games, suggests per-game profiles, and helps capture diagnostics.

Both are local Mac downloads. No cloud generation, billing, hosted storage, Steam, games, model weights, or compatibility backend is bundled.

Download: https://jbcdevelopment.dev/downloads.html
