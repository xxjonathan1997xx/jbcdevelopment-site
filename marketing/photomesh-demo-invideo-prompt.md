## VOICEOVER
I built PhotoMesh Studio to make 3D asset prep easier for indie game developers.

Start with a clean object photo, then run a local reconstruction workflow on your Mac.

PhotoMesh imports the raw GLB, checks the asset health, and shows a 3D preview so you can inspect the result.

From there, you can optimize the GLB, fix scale or pivot issues, generate LODs, and export packs for Unity, Godot, or Three.js.

One photo cannot perfectly know the hidden back side of an object, so every model still needs review.

But for props, prototypes, and early game assets, this gives you a faster local starting point.

Download the free Mac app at jbcdevelopment.dev.
